# Equivalencias ASP.NET Core vs Django

| ASP.NET Core | Django |
|---|---|
| Controller | ViewSet / APIView |
| Entity | Model |
| DbContext | Django ORM |
| DbSet | Model.objects |
| Migration | makemigrations/migrate |
| Repository | Clase Repository |
| Unit Of Work | transaction.atomic |
| Service Layer | Services |
| Dependency Injection | Inyección manual |
| Middleware | Middleware |
| Logging | logging |
| appsettings.json | settings.py |
| Program.cs | manage.py / settings.py |
